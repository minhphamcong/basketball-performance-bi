# Power BI report

1. Run the preparation script in the root README to create `data/processed/team_game_stats.csv`.
2. In Power BI Desktop, choose **Get data → Text/CSV** and select that generated file.
3. Create report pages for team overview and game-by-game performance.
4. Useful visuals: wins/losses cards, points by game, point differential, shooting percentages, rebounds/assists/turnovers by result, and home/away comparison.
5. Add slicers for season, team, opponent, and venue where appropriate.
6. Display the selected date range and define each metric. Keep attempts visible alongside shooting percentages.
7. Save the `.pbix` here if its size and embedded data are appropriate for the repository and the dataset license permits it. Otherwise keep it local and commit screenshots plus reproduction instructions.

Validate a few displayed figures against the generated CSV before presenting the report.
